# POO-PROMOCION-SCALA
Ejemplos de los conceptos de Programación Orientada a Objetos en Scala 3, sobre el dominio de un cine.

## Requisitos
- Scala 3 (instalado con Coursier)

## Cómo ejecutar
En la carpeta del proyecto:

    scala run .

## Ejemplos
- `Sala.scala`: encapsulamiento (butacas privadas, reserva validada)
